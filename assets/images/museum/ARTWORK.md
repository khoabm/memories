# Museum artwork

Generated with the built-in imagegen tool, using the supplied museum wireframe as the architectural, composition, material and palette reference. No external stock photographs or runtime library. Original PNGs remain in the Codex generated_images folder; optimized, alpha-preserving WebP copies are stored here at 840px and 1600px widths. Architectural mobile crops use CSS; mobile exhibits use a separate, single-case composition. Unknown deliberately contains no object and uses the empty display/light system.

All critical titles, copy, ticket fields and card inscriptions also exist as real HTML text. Sound is original synthesized Web Audio gallery ambience and material cues, with no audio download.
